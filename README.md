# Cutefish Music

**English** | **[Türkçe](#türkçe)**

---

## English

A lightweight, frameless macOS Sequoia-inspired glassmorphism music player built for **CutefishOS** (`cutefish-music`).

### Features
- **Automatic Light/Dark Theme Sync:** Syncs directly with CutefishOS Appearance (`org.cutefish.Services`) and includes a quick theme toggle.
- **Native System Locale (`gettext`):** Defaults to English for ISO integration and automatically switches to Turkish (`tr_TR`) based on system locale.
- **Frameless Cutefish Window:** Borderless glassmorphism window with integrated window controls.
- **Persistent Library & Favorites:** Remembers your selected music folder and favorite tracks.

### Installation
```bash
sudo apt install ./cutefish-music_1.0.0_all.deb
```

## Türkçe

**CutefishOS** için geliştirilmiş, çerçevesiz (frameless) ve macOS Sequoia esintili cam efektli modern müzik çalar (`cutefish-music`).

### Özellikler
- **Otomatik Açık/Koyu Tema Uyumu:** CutefishOS görünüm ayarlarıyla (`org.cutefish.Services`) otomatik senkronize olur; ayrıca hızlı tema geçiş düğmesi içerir.
- **Yerel Sistem Dili (`gettext`):** Varsayılan olarak İngilizce gelir; sistem Türkçe (`tr_TR`) kurulduğunda otomatik Türkçe açılır.
- **Çerçevesiz Pencere Tasarımı:** CutefishOS masaüstü estetiğiyle bütünleşen cam efektli modern arayüz.
- **Kalıcı Kitaplık ve Favoriler:** Seçtiğiniz müzik klasörünü ve favori şarkılarınızı kalıcı olarak saklar.

### Kurulum
```bash
sudo apt install ./cutefish-music_1.0.0_all.deb
```
